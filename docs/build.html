Define the data model

Create app/models.py. A request model describes what the client may send. A response model also includes values generated by the server. This is the API contract. [1, 5]

Fields in a task
FieldRuleReason
titleRequired string, 1–120 characters; whitespace-only text is rejectedA task needs a visible name
descriptionOptional string, at most 500 characters; default nullExtra detail is optional
statustodo, in_progress or done; default todoKeep workflow values consistent
priorityInteger from 1 to 5; default 3Reject values outside the agreed scale
id, created_at, updated_atGenerated by the repositoryIdentify the record and track changes

The central constraint is short:

Priority field
priority: int = Field(default=3, ge=1, le=5)

ge means “greater than or equal to”; le means “less than or equal to”. A type hint alone does not validate an ordinary Python variable. FastAPI uses the Pydantic model to validate incoming API data. field_validator adds the rule that a title cannot contain only spaces.

Copy the complete model below, including the imports. TaskCreate and TaskReplace share the input fields. TaskRead adds the server-generated fields. The two small metadata models are used in Step 7.

app/models.py — complete file to copy
app/models.py
"""Pydantic models used by the Task Manager API."""

from datetime import datetime
from enum import Enum

from pydantic import BaseModel, Field, field_validator


class TaskStatus(str, Enum):
    """Allowed workflow states for a task."""

    TODO = "todo"
    IN_PROGRESS = "in_progress"
    DONE = "done"


class TaskData(BaseModel):
    """Fields supplied by a client when creating or replacing a task."""

    title: str = Field(
        min_length=1,
        max_length=120,
        examples=["Prepare the FastAPI demo"],
    )
    description: str | None = Field(
        default=None,
        max_length=500,
        examples=["Test every endpoint before the group presentation."],
    )
    status: TaskStatus = Field(default=TaskStatus.TODO)
    priority: int = Field(default=3, ge=1, le=5)

    @field_validator("title")
    @classmethod
    def title_must_contain_text(cls, value: str) -> str:
        """Trim the title and reject values made only of whitespace."""

        cleaned = value.strip()
        if not cleaned:
            raise ValueError("title must contain at least one visible character")
        return cleaned

    @field_validator("description")
    @classmethod
    def normalise_description(cls, value: str | None) -> str | None:
        """Trim an optional description and store an empty value as null."""

        if value is None:
            return None
        cleaned = value.strip()
        return cleaned or None


class TaskCreate(TaskData):
    """Request body for POST /tasks."""


class TaskReplace(TaskData):
    """Request body for PUT /tasks/{task_id}."""


class TaskRead(TaskData):
    """Task representation returned to API clients."""

    id: int
    created_at: datetime
    updated_at: datetime


class ApiMessage(BaseModel):
    """Small response model used for API metadata."""

    message: str
    docs_url: str
    redoc_url: str


class HealthResponse(BaseModel):
    """Response model for the health endpoint."""

    status: str

Store tasks in a repository

Create app/repository.py. A repository is a Python class that stores and retrieves records. It keeps storage work outside the route functions. In this project, a dictionary stores each task under its ID.

  1. create combines the validated fields with a new ID and UTC timestamps.
  2. list_all returns tasks in ID order, optionally filtered by status and priority.
  3. get, replace and delete raise TaskNotFoundError when a task does not exist.

_next_id increases after each creation. Deleting a task does not reuse its ID. model_copy(deep=True) prevents a caller from directly changing the stored object. The lock protects operations within one process; it does not share data between server processes.

app/repository.py — complete file to copy
app/repository.py
"""Thread-safe in-memory storage for the Task Manager API."""

from datetime import datetime, timezone
from threading import RLock

from .models import TaskCreate, TaskRead, TaskReplace, TaskStatus


class TaskNotFoundError(LookupError):
    """Raised when a task identifier does not exist."""


class TaskRepository:
    """Store task records in memory for a small teaching example."""

    def __init__(self) -> None:
        self._tasks: dict[int, TaskRead] = {}
        self._next_id = 1
        self._lock = RLock()

    def list_all(
        self,
        *,
        status: TaskStatus | None = None,
        priority: int | None = None,
    ) -> list[TaskRead]:
        """Return tasks in identifier order with optional filters."""

        with self._lock:
            tasks = sorted(self._tasks.values(), key=lambda task: task.id)
            if status is not None:
                tasks = [task for task in tasks if task.status == status]
            if priority is not None:
                tasks = [task for task in tasks if task.priority == priority]
            return [task.model_copy(deep=True) for task in tasks]

    def create(self, data: TaskCreate) -> TaskRead:
        """Create and store a new task."""

        with self._lock:
            now = _utc_now()
            task = TaskRead(
                id=self._next_id,
                created_at=now,
                updated_at=now,
                **data.model_dump(),
            )
            self._tasks[task.id] = task
            self._next_id += 1
            return task.model_copy(deep=True)

    def get(self, task_id: int) -> TaskRead:
        """Return one task or raise TaskNotFoundError."""

        with self._lock:
            task = self._tasks.get(task_id)
            if task is None:
                raise TaskNotFoundError(task_id)
            return task.model_copy(deep=True)

    def replace(self, task_id: int, data: TaskReplace) -> TaskRead:
        """Replace all editable fields of an existing task."""

        with self._lock:
            current = self._tasks.get(task_id)
            if current is None:
                raise TaskNotFoundError(task_id)
            updated = TaskRead(
                id=current.id,
                created_at=current.created_at,
                updated_at=_utc_now(),
                **data.model_dump(),
            )
            self._tasks[task_id] = updated
            return updated.model_copy(deep=True)

    def delete(self, task_id: int) -> None:
        """Delete one task or raise TaskNotFoundError."""

        with self._lock:
            if task_id not in self._tasks:
                raise TaskNotFoundError(task_id)
            del self._tasks[task_id]


def _utc_now() -> datetime:
    """Return a timezone-aware timestamp."""

    return datetime.now(timezone.utc)

Connect GET and POST routes

Create app/main.py using the complete first version below. The factory create_app creates an application with its own repository. This also lets tests start with empty storage. [2, 3]

The decorator connects an HTTP method and path to a function. data: TaskCreate tells FastAPI to validate the JSON body. response_model describes the returned data. POST explicitly uses 201 Created; GET uses 200 OK.

app/main.py — first version
from fastapi import FastAPI, status

from .models import TaskCreate, TaskRead
from .repository import TaskRepository


def create_app(repository: TaskRepository | None = None) -> FastAPI:
    task_repository = repository or TaskRepository()
    application = FastAPI(title="FastAPI Task Manager")

    @application.get("/tasks", response_model=list[TaskRead])
    def list_tasks() -> list[TaskRead]:
        return task_repository.list_all()

    @application.post(
        "/tasks",
        response_model=TaskRead,
        status_code=status.HTTP_201_CREATED,
    )
    def create_task(data: TaskCreate) -> TaskRead:
        return task_repository.create(data)

    return application


app = create_app()

Trace a valid and invalid request

In Swagger UI, open POST /tasks, choose Try it out, replace the body below and select Execute once.

Valid JSON request
{
  "title": "Rehearse the demo",
  "status": "todo",
  "priority": 5
}

Under Server response, expect 201. The body contains your title and priority, plus description: null, an ID and timestamps. The first ID is 1 only in a fresh repository. Repeating POST creates another task; it does not update the old task.

  1. POST /tasksThe client sends JSON.
  2. PydanticPriority 5 passes the model rules.
  3. RouteThe function receives TaskCreate.
  4. RepositoryA task and ID are stored.
  5. 201 + JSONFastAPI sends the task back.

Change only priority to 9 and execute again. Expect 422. The error includes loc: ["body", "priority"] and a maximum-value constraint of 5. Exact error text can vary with the installed Pydantic version. The route does not create the invalid task.

app/main.py — final version — complete file to copy
app/main.py — final version
"""Application factory and HTTP routes for the Task Manager API."""

from typing import Annotated

from fastapi import FastAPI, HTTPException, Path, Query, Response, status

from .models import (
    ApiMessage,
    HealthResponse,
    TaskCreate,
    TaskRead,
    TaskReplace,
    TaskStatus,
)
from .repository import TaskNotFoundError, TaskRepository


def create_app(repository: TaskRepository | None = None) -> FastAPI:
    """Create an application with an injectable task repository."""

    task_repository = repository or TaskRepository()
    application = FastAPI(
        title="FastAPI Task Manager",
        summary="A small REST API for managing presentation tasks.",
        description=(
            "A teaching example that demonstrates CRUD routes, Pydantic validation, "
            "query parameters, HTTP status codes, and generated OpenAPI documentation."
        ),
        version="1.0.0",
        contact={"name": "COMP10020 FastAPI Group"},
        license_info={"name": "MIT"},
        openapi_tags=[
            {"name": "meta", "description": "API information and service health."},
            {"name": "tasks", "description": "Create, read, replace, and delete tasks."},
        ],
    )

    @application.get("/", response_model=ApiMessage, tags=["meta"])
    def read_root() -> ApiMessage:
        """Point new users to the generated API documentation."""

        return ApiMessage(
            message="FastAPI Task Manager is running.",
            docs_url="/docs",
            redoc_url="/redoc",
        )

    @application.get("/health", response_model=HealthResponse, tags=["meta"])
    def read_health() -> HealthResponse:
        """Provide a simple health check for clients and hosting platforms."""

        return HealthResponse(status="ok")

    @application.get("/tasks", response_model=list[TaskRead], tags=["tasks"])
    def list_tasks(
        task_status: Annotated[
            TaskStatus | None,
            Query(alias="status", description="Return only tasks in this workflow state."),
        ] = None,
        priority: Annotated[
            int | None,
            Query(ge=1, le=5, description="Return only tasks with this priority."),
        ] = None,
    ) -> list[TaskRead]:
        """List tasks, optionally filtering by status and priority."""

        return task_repository.list_all(status=task_status, priority=priority)

    @application.post(
        "/tasks",
        response_model=TaskRead,
        status_code=status.HTTP_201_CREATED,
        tags=["tasks"],
    )
    def create_task(data: TaskCreate) -> TaskRead:
        """Create a task after Pydantic validates the request body."""

        return task_repository.create(data)

    @application.get("/tasks/{task_id}", response_model=TaskRead, tags=["tasks"])
    def read_task(
        task_id: Annotated[int, Path(gt=0, description="Numeric task identifier.")],
    ) -> TaskRead:
        """Return one task by identifier."""

        try:
            return task_repository.get(task_id)
        except TaskNotFoundError as error:
            raise _not_found(task_id) from error

    @application.put("/tasks/{task_id}", response_model=TaskRead, tags=["tasks"])
    def replace_task(
        task_id: Annotated[int, Path(gt=0, description="Numeric task identifier.")],
        data: TaskReplace,
    ) -> TaskRead:
        """Replace all editable fields of a task."""

        try:
            return task_repository.replace(task_id, data)
        except TaskNotFoundError as error:
            raise _not_found(task_id) from error

    @application.delete(
        "/tasks/{task_id}",
        status_code=status.HTTP_204_NO_CONTENT,
        response_class=Response,
        tags=["tasks"],
    )
    def delete_task(
        task_id: Annotated[int, Path(gt=0, description="Numeric task identifier.")],
    ) -> Response:
        """Delete a task and return an empty 204 response."""

        try:
            task_repository.delete(task_id)
        except TaskNotFoundError as error:
            raise _not_found(task_id) from error
        return Response(status_code=status.HTTP_204_NO_CONTENT)

    return application


def _not_found(task_id: int) -> HTTPException:
    """Build the consistent 404 response used by task endpoints."""

    return HTTPException(
        status_code=status.HTTP_404_NOT_FOUND,
        detail=f"Task {task_id} was not found.",
    )


app = create_app()

    assert invalid_priority.status_code == 422

        "title": "Deliver the FastAPI presentation",
        "description": None,
        "status": "done",
        "priority": 5,

    assert response.status_code == 200
    updated = response.json()

    assert updated["created_at"] == created["created_at"]
    assert updated["updated_at"] >= created["updated_at"]
    assert updated["title"] == replacement["title"]
    assert updated["description"] is None
    assert updated["status"] == "done"
    assert updated["priority"] == 5


def test_replace_missing_task_returns_404(client: TestClient) -> None:
    response = client.put(
        "/tasks/100",
        json={"title": "Missing", "status": "todo", "priority": 1},

    assert response.status_code == 404


def test_delete_task_returns_204_and_removes_record(client: TestClient) -> None:
    created = create_sample_task(client)

    deleted = client.delete(f"/tasks/{created['id']}")

    assert deleted.content == b""

def test_list_filters_by_status_and_priority(client: TestClient) -> None:

3. Explain a storage upgrade

Sketch how a SQLite repository would keep tasks after a restart. Keep the HTTP paths and models unchanged. Identify where create, read, replace and delete operations would use database queries.

Success criteria: distinguish persistent storage from the present dictionary and explain why memory cannot coordinate several worker processes. Database implementation is optional.

Check your understanding

Why does invalid priority return 422 before a task is created?

FastAPI asks Pydantic to validate the request against TaskCreate before calling the route. If validation fails, the route does not call the repository.

What is the difference between 404 and 422?

404 means a valid positive ID has no stored record. 422 means request data fails the declared rules, such as priority 9 or task ID 0.

Why give each test a fresh repository?

Tests must not depend on another test creating or deleting tasks. Fresh storage makes the initial state predictable and keeps tests independent.

Can GitHub Pages run this FastAPI server?

No. Pages serves this static HTML, CSS and JavaScript resource. Run the Python API locally with Uvicorn. An API deployment would require a separate server.

Completion checklist: you can explain a request from client to stored task; demonstrate 200, 201, 204, 404 and 422; run eight tests; and describe why the data disappears after a restart.
